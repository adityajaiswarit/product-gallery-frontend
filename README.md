# Product Card Gallery — Frontend

Reconstructed starter frontend for Experiment 8. Built with React and Vite.

## Run locally
1. Install Node.js.
2. From this folder run:
   ```sh
   npm install
   npm run dev
   ```
3. Open the URL printed by Vite (usually http://localhost:5173).

The frontend expects the Spring Boot API at `http://localhost:8080/products` by default. Set `VITE_API_URL` to override it.
